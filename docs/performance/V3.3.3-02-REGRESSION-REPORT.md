## 6. 残余风险

1. 500k 球员的未筛选列表仍需约 1.0 s（计数物化 UNION + 排序），已定位但未解决，
   方案评估见《OPTIMIZATION-REPORT.md》第 5 节。
2. 导入吞吐未优化（约 176~178 人/秒），大批量导入仍是线性成本。
3. 事件批量化只在节点层生效；外部直接调用 `TaskEventBus.append` 的路径仍逐条提交。
4. 位置筛选使用 `upper(trim(position))`，无法命中 `(fm_save_id, position)` 索引，
   500k 球员 + 10 万转会时约 630 ms；若后续成为热点，可考虑写入时规范化位置字段。
