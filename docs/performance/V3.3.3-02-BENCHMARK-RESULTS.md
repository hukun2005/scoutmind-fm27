## 5. 结果指纹（语义未变）

除以下两项外，所有用例的 `result_digest` 与基线完全一致：

- `api_transfers_position`：基线没有指纹（请求直接报错），优化后产生正常结果；
- `agent_event_replay_500`：优化后的基准新增了「事务批量」用例，重放事件数量不同
  （属于基准数据集差异，不是接口行为变化）。

球员列表、搜索、筛选、详情、转会列表、转会联赛+位置等指纹均未变化，
并且新增的 `tests/test_v333_performance.py` 用独立数据集锁定了多位置字符串的筛选语义。
