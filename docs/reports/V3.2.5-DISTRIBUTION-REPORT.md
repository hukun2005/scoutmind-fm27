# V3.2.5 安装与分发现状报告（Phase 8）

**状态：NOT_RUN（分析完成，未产出安装包）**

## 1. 现有打包能力

`scripts/publish-windows.ps1`：

- `dotnet publish` 自包含、单文件发布 `ScoutMind.LiveReader.exe` 与 `ScoutMind.Agent.exe`（默认 `win-x64`）；
- 两个 exe 同目录，Agent 默认调用同目录的 Reader；
- 复制 `compatibility.json` 与 `scanner.sample.json`。

## 2. 缺口

| 要求 | 现状 |
| --- | --- |
| Windows 安装器（MSI/EXE） | 无（没有 Inno/NSIS/WiX 工程） |
| 后端 Python 运行时打包 | 无（仍需源码环境 + venv） |
| 数据库初始化工具 | 只有 Alembic，无用户级初始化向导 |
| 首次启动向导 | 无 |
| 备份/恢复工具 | 无 |
| 升级保留用户数据 | 无安装器，无从谈起 |
| 代码签名 | 无证书 |

## 3. 依赖与许可证

- 读取器**不要求**用户安装 FMSuperScout：上游 `third_party/FMSuperScout` 是 MIT License
  （Copyright 2026 mavarobli），以源码形式编译进读取器；分发时必须附带该许可证文本。
- .NET 运行时以 self-contained 方式随 exe 发布（体积换免安装运行时）。

## 4. 结论

“其他使用者下载即用”的目标**未达成**：目前仍需开发者手动跑 `scripts/setup.ps1`、启动后端与前端。
V3.2.5 不能声称具备正式安装包。
