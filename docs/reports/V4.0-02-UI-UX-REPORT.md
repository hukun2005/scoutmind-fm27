## 2. 信息层级（统一约定）

1. **结论**：`InsightPanel` 一句话说明「当前是什么情况、下一步做什么」，并标注 `数据事实` 或 `规则生成`。
2. **指标**：`StatStrip` 紧凑指标条，缺值显式显示 `—`，不按 0 计算。
3. **风险 / 机会**：风险、缺口、机会卡紧随结论。
4. **明细**：表格与列表保持既有列与操作。
5. **高级分析**：低频筛选项、诊断、证据与审计默认折叠，展开方式不变。

## 3. 页面改造（按页面）

### 3.1 球员探索 `/players`
- 新增「球探概览」结论面板：可见球员、覆盖度、缺失字段与下一步；规则生成声明独立展示。
- 指标条：球员数、平均年龄、CA 覆盖、身价覆盖、关注数（缺失显示 `—`）。
- 主筛选仅保留姓名/位置/年龄；俱乐部、潜力、CA、身价、关注、覆盖度收进「更多筛选」。
- 列表空态继续提供「同步游戏数据」引导，与结论面板文案不重复。

### 3.2 球员详情 `/players/:id`
- 新增「决策摘要」：合同、状态、估值偏离、成长空间、角色评分，标注为规则生成。
- 新增分组锚点导航（能力 / 表现与成长 / 转会与估值 / 状态与合同），原有 11 个区块全部保留。
- hero 事实区改为紧凑指标条；档案区移至页面末尾。

### 3.3 球员对比 `/compare`
- 新增「差异结论」与指标条；对比表高亮领先值并显示差值。
- 雷达图移至对比表之后；无数据维度显示 `—`，不参与领先判断。
- 球员详情页/表格入口行为未变。

### 3.4 引援机会 `/recruitment`
- 新增「引援结论」：评分覆盖率、优先机会数量、主要风险来源与下一步。
- 新增 Top3「优先机会」卡：等级、评分、强项、风险、成本、评分覆盖率；成本展开区保留 `cost_estimate.basis` 来源。
- 完整表格、短名单、隐藏价值与全局对比入口全部保留。

### 3.5 转会情报 `/transfers`
- 新增「转会情报摘要」与紧凑指标；首屏顺序调整为：成交事件 → 俱乐部画像 → 费用结构 → 相似成交 → 复盘。
- 「转会资金流向」卡保留，位置下移但契约不变（按币种拆分）。
- 俱乐部卡可点击筛选，原有筛选与分页行为不变。

### 3.6 AI 足球总监 `/director`
- 新增「总监简报」（数据事实）：存档数据量、更新时间、完整度、已知缺口与下一步；不预先给结论。
- 任务入口改为 7 张任务卡（阵容/补强/年轻引援/培养/出售/年龄结构/引援计划），任务文本与后端意图保持一致；其余问题保留为轻量入口。
- 回答改为报告式：任务目标 → 指标 → 依据分析 → 风险与数据缺口 → 下一步 → 来源与声明；不展示内部 JSON。
- 原有「本地规则引擎」标识、推荐球员卡与「加入关注」操作保留。

### 3.7 AI 球探助手 `/agent`
- 新增「常用任务」输入条，复用既有建议问题与同一后端接口。
- 回答增加「结论 / 依据分析 / 相关球员·下一步」结构化标签；引用、数据缺口与免责声明保留。
- 会话历史、球员卡跳转与错误提示未改。

### 3.8 AI 转会总监 `/transfer-director`
- 顶部新增「当前任务与结论」面板：当前目标、存档规模、报价口径、数据边界（历史成交需手动导入）。
- 新增指标条：存档球员、合同覆盖、转会记录、谈判数、已挂牌机会。
- 新增分区导航（机会雷达 / 成交策略 / 报价工作台 / 转会情报 / 买入 / 出售 / 租借 / 合同 / 谈判），与既有页签共用状态。
- 报价金额仍由确定性引擎计算，界面明确声明 AI 不决定金额；所有工作台与抽屉功能保留。

### 3.9 游戏数据 `/data`
- 新增「同步状态」结论面板：游戏连接、当前存档识别、最近同步、待确认问题与下一步。
- 新增指标条：已导入球员、俱乐部、转会、最近同步、待确认。
- 主流程顺序保持「数据健康 → 游戏连接/文件导入 → 数据状态」；FMSuperScout、CSV、导入历史、覆盖度、兼容性等仍在「开发者诊断（高级）」中默认折叠。

### 3.10 存档管理 `/save-identity`
- 新增「存档状态」结论面板与指标条（存档数量、当前存档、球员/快照、最近读取、身份记录）。
- 新增「我的存档」卡片列表：版本、build、球员/快照/转会、最近读取、当前标记。
- 新增切换存档：切换前二次确认；存在排队/运行中的导入任务时明确提示任务会失效；切换后本页与全局数据源同步刷新。
- 身份证据、采集闸门、Worker/网络诊断、会话与审计收进「高级」折叠，默认不展开；后端判定与审计未改。

## 4. 契约保护与回归
