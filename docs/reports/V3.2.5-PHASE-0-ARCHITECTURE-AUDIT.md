## 4. Worker 现状（SM-136 差距）

检索 `backend/app` 全目录：没有 worker / lease / heartbeat / cancel 相关表或服务。
现有能力只有：导入移出事件循环（`asyncio.to_thread`）、`GET /imports`、`409 import_in_progress`、
启动时把 `running` 标为 `failed` 并写 `interrupted` 行、Agent 超时后按 `scan_id` 核验。

缺口：202、持久化队列、批次进度、取消、重试、Worker 生命周期、多 Worker 领取。

## 5. 前端现状（SM-138 差距）
