# V3.2.5 前端 Import Center 报告（Phase 6）

**状态：NOT_RUN（依赖 SM-136 Worker）**

## 1. 现状

前端没有导入任务中心：没有任务列表、详情、进度条、取消/重试按钮，也没有 Playwright 导入用例。
现有页面仍以球员/成长/转会/自动采集为主。

## 2. 为什么没有先做页面

- 进度必须来自后端持久化数据（任务书 4.10 明确禁止前端计时器伪造进度）；
- 后端没有 `total/processed/stage`，也没有 `cancel/retry` 接口；
- 先做页面会得到一个“永远显示 0% 或假进度”的界面，违反“不能虚拟进度”的验收要求。

## 3. 依赖顺序

```text
Worker 数据模型/API（Phase 4） → Worker（Phase 5） → Import Center（Phase 6）
```

## 4. 结论

Import Center **未实现**，因此 V3.2.5 不能宣称“前端导入进度”完成。
