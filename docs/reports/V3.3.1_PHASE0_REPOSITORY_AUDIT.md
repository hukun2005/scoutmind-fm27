## 4. 关键约束与风险

1. **真实 FM27 数据未参与本轮**：所有验证使用测试库与 Playwright 接口 Mock；真实联调标记 `NOT_RUN`。
2. **缺失值**：`market_value`、`ca`、`pa`、`fee` 均可能为 `NULL`，图表与对比必须显示「暂无数据」，不得按 0 参与排名。
3. **多币种**：`transfers.currency` 可能非 EUR；资金流向按币种分组，不跨币种相加。
4. **转会状态**：只有 `completed` 计入成交；`loan` 单列；`agreed / rumor / cancelled` 不计入实际收支。
5. **路由顺序**：`/players/{instance_id}` 会吞掉 `/players/compare` 这类静态路径，新接口避免与其同级冲突（使用 `/visualizations/*` 与 `/search`）。
6. **共享文件**：`App.vue`、`router/index.ts`、`utils/chart.ts`、`types/players.ts` 由单一执行者按 B → A → C 顺序修改，避免并行冲突。
7. **单 PR 偏差**：任务书建议 3 个 Agent / 3 个 PR；本轮为单执行者，采用 1 个集成分支、分功能提交、1 个 PR，以避免共享文件冲突；该偏差在最终报告登记。
