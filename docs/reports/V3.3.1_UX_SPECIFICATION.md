# V3.3.1 UI/UX 说明

## 1. 设计原则

- 专业但不晦涩：界面以中文说明为主，保留 CA/PA、ST/AMC 等行业缩写，并在表头或脚注解释。
- 一屏优先：核心结论在上，明细可下钻；图表与表格不重复堆叠。
- 缺失可解释：任何空值显示「暂无数据 / —」，不补 0、不装作完整。
- 深色球场氛围：沿用 V3.3.0 的 Token、ChartCard 与空/错误/加载组件，不新增主题。

## 2. 导航

分组保持不变，避免把功能拆成更多一级入口：

| 分组 | 页面 |
| --- | --- |
| 总览 | 首页 |
| 球探分析 | 阵容分析、球员中心、**球员对比（新增）**、引援中心、转会情报、球员发展、表现分析、AI 体育总监 |
| 数据管理 | 数据中心、数据治理、身份复核、身份中心、存档身份、待确认球员 |
| 工具 | 角色球探、关注名单 |

- 侧栏保留「功能说明」tooltip，低频页面不抢占主导航。
- 当前路由高亮；移动端折叠为抽屉。

## 3. 顶栏与全局搜索

- 顶栏右侧新增搜索按钮，显示 `Ctrl K` 提示；窄屏隐藏快捷键文字。
- `Ctrl/⌘ + K` 随时打开，`Esc` 关闭，打开后自动聚焦输入框。
- 面板层级：输入 → 分类页签 → 结果分组 → 快捷键提示。
- 结果行：类型徽标、名称、副标题、能力/费用摘要；球员行右侧「+ 对比」。
- 最近搜索仅本地保存，最多 6 条；无查询时展示。
- 失败与空结果均有独立文案，不清空用户输入。

## 4. 首页

- 保留 V3.3.0 的 KPI、阵容结论、风险与最近转会。
- 快捷入口新增「球员对比」，与球员中心、阵容、引援并列。
- 无数据时仍以「同步游戏数据」为主行动，不展示空图表。

## 5. 球员中心

- 顶部：标题、说明、对比入口（显示 `n/4`）、刷新。
- 指标卡：球员数、平均年龄、CA/PA 覆盖、关注人数等（沿用 V3.3.0）。
- 新增「球员价值分布」图表卡，可随俱乐部筛选联动。
- 列表：
  - 表格 / 卡片切换（右上角分段控件）；
  - 表格新增「对比」列，按钮支持加入/已加入；
  - 卡片显示姓名、位置、年龄、俱乐部、CA/PA/身价与操作；
  - 两种视图共用服务端筛选、排序、分页；
  - 空库与筛选无结果文案区分，分别引导同步或清除条件。
- URL 支持 `club_id`、`position`、`position_group`、`query`，用于搜索与热力图跳转。

## 6. 球员详情

- 新增「能力结构雷达」，位于属性表之前；无足够类别数据时不显示。
- 雷达脚注说明类别均值口径，避免被误读为 CA/PA。
- 成长趋势、合同、转会历史保持原有结构与口径。

## 7. 阵容分析

- 页面顶部新增「位置深度热力图」，先给结论再给明细。
- 每个位置格：位置名、人数/需求、主力、替补、状态；颜色表达空缺/偏薄/充足。
- 点击位置进入球员中心对应区域，减少手动筛选。
- 窄屏自动改为 2 列，避免横向滚动。

## 8. 转会情报

- 页签上方新增「转会资金流向」，按币种分别成图。
- 柱状图固定顺序：买入、卖出、租借收入、租借支出、净支出。
- 脚注说明只统计已完成、租借单列、附加条款不计入、币种不合并。
- 没有「我的俱乐部」时显示说明，而不是空图。

## 9. 球员对比

- 选择区：搜索框、已选 chips（序号、姓名、替换、移除）、候选列表。
- 少于 2 人：空状态引导；达到 4 人后新增按钮给出提示。
- 结果区顺序：雷达 → 资料表 → 确定性摘要 → 继续操作。
- 资料表横向自适应，首列固定为项目名；窄屏允许表格内部横向滚动，但页面本身不溢出。
- 摘要只列事实，不出现综合评分或推荐语。

## 10. 桌面适配与可访问性

已验证分辨率：1280×720、1366×768、1440×900、1920×1080，核心页面均无页面级横向滚动。

- 交互元素使用 `button` / `a` / `role`，提供 `aria-label`、`aria-pressed`、`aria-selected`。
- 搜索面板支持完整键盘操作；图表提供 `aria-label` 描述。
- 颜色不是唯一信息载体：状态同时有文字（空缺/偏薄/充足）。
- 动效遵循 `prefers-reduced-motion`（沿用全局样式）。
