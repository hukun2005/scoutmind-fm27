## 2. 阻塞发布的三件事

1. **没有可信的当前游戏日期**：报文日期来自“下一场比赛”，不能驱动自动历史快照；
   需要找到真正的当前日期字段并在两个以上游戏日期上做独立验证。
2. **没有持久化后台 Worker**：长导入仍占用一次 HTTP 请求；已移出事件循环、可查询、可恢复、可防重入，
   但没有 202 + 行级进度 + 取消/重试，前端也因此没有进度页。
3. **真实多存档未验证**：只有一个真实存档，自动化隔离用例不能替代真实切换。
