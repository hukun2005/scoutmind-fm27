# V3.3.1 测试计划

## 1. 范围

- 后端：新增搜索与可视化只读接口，球员详情摘要新增字段。
- 前端：全局搜索、球员对比、四类新图表、导航/首页/球员中心改造。
- 回归：V3.3.0 及更早的球员、阵容、转会、治理、身份与迁移能力。

不在范围：真实 FM27 客户端联调、真实存档大规模性能压测、桌面安装包重打包。

## 5. 回归

- 后端全量 `pytest`。
- 前端全量 Playwright（含 V3.3.0、治理、待确认球员旧用例）。
- `npm run build` 必须通过 `vue-tsc --noEmit`。

## 6. 判定标准

- 新增用例全部通过；
- 旧用例无新增失败；
- 构建零类型错误；
- 缺失值、币种、存档隔离三类硬约束有对应用例；
- 未执行项必须标记 `NOT_RUN`，不得写成 PASS。
