## 3. 首页（工作台）

新增与调整：

1. 首屏标题使用「欢迎回来，{俱乐部}」，副标题展示联赛与游戏版本；存档、连接状态、最近导入以状态条呈现。
2. 核心指标：一线队人数、平均年龄、阵容综合评分、主要短板、合同风险。
3. 「AI 总监简报」：最大问题、引援机会、合同风险、值得关注球员、下一步，均来自 `/squad/overview` 与 `/recruitment/hidden-value` 的真实字段；脚注明确声明为规则生成，不是游戏隐藏属性。
4. 「重要提醒」独立成块，只保留可行动事项。
5. 快捷入口改为任务导向：分析阵容、搜索球员、发现引援机会、比较球员、生成转会策略、向 AI 足球总监提问。
6. 图表、覆盖度、导入记录继续放在「更多数据洞察」折叠区。

## 4. 阵容分析（五层结构）

1. **球队概览**：俱乐部、联赛、一线队人数、平均年龄、阵容完整度、合同风险、六维综合评分与各维度明细。
2. **主执教俱乐部**：无本队时唯一必须先完成的操作，保留来源/可信度/手动指定标签。
3. **阵容诊断**：最大优势、最明显薄弱位置、主力年龄结构、替补深度、潜力储备、最优先补强；每条给出依据或「数据缺失」原因。
4. **补强优先级**：保留原有缺口评分与「去引援」跳转（`/recruitment?slot=`）。
5. **位置深度**：紧凑热力图保留，后接可按位置展开的明细表。
6. **重点球员**：核心球员（CA）、高潜力球员（PA−CA）、合同风险球员（6–12 个月到期）。
7. **更多阵容分析**（默认折叠）：六维权重、雷达/年龄图、阵容构成、短板表、年龄结构、工资、合同、接班规划。

缺失值处理：平均年龄缺失显示「年龄数据缺失」并在维度条显示「缺失：缺少工资字段」等，不出 0。
