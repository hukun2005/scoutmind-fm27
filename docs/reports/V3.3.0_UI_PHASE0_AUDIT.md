## 4. 组件与重复情况

现有可复用组件（保留，不重复造轮子）：`PageHeader`、`SectionCard`、`DataTable`、`EmptyState`、`ErrorState`、`LoadingBlock`、`KpiCard`、`StatHeader`、`ChartCard`、`EChart`、`CoverageBar`、`NumberCell`、`CompareBar`、`ConfidenceTag`、`ScoreBadge`、`AppIcon`、`CapturePanel`。

问题：

1. `PageHeader` 的 `eyebrow` 让每个页面标题上方都堆一行全大写英文。
2. 各页面各自实现筛选网格，字段标签、间距、折叠方式不一致；部分页面直接暴露后端字段名。
3. `DataTable` 只接受 `empty-title`/`empty-description` 字符串，页面无法在同一张表内呈现「库空 → 引导同步 / 筛选空 → 清除条件」两种动作。
4. 没有 `FilterPanel`（常用 + 高级折叠）公共组件。
5. 没有设置页，令牌配置以弹窗形式常驻顶栏。
6. `sm-eyebrow` 在 5 个页面模板内被复用为英文装饰标题。
