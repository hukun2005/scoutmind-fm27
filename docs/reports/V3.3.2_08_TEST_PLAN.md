# V3.3.2-08 测试计划与覆盖

## 1. 目标

验证在线持续学习引擎在真实约束下成立：只学习可观测的真实数据、按存档隔离、事件可去重、增量不重复、样本不足时回退、迁移可往返、前端不暴露开发参数。

## 2. 测试分层

| 层级 | 文件 | 覆盖 |
|---|---|---|
| 事件识别 | `backend/tests/test_v332_08_online_learning.py` | 成交/协议/租借/挂牌/俱乐部变化/用户确认谈判与反馈 |
| 去重与恢复 | 同上 | 跨轮重复、同批重复、取消后检查点续跑 |

| 回归 | 既有 transfer/director/scan/import/migration 测试 | 不得降低既有断言 |

## 3. 关键断言

1. 首次学习吸收真实历史，但第二次运行不重复写入。
2. `status='agreed'` 不进入价格统计；`synthetic/demo` 来源不写入。
3. 原生读取器不提供转会：状态接口明确 `native_reader_transfers=false`。
4. 俱乐部变化候选只能是 `UNVERIFIED`，金额为空，禁止推断价格。
5. 无真实成交时策略返回 `available=false` 且 `patterns` 为空。
6. 分页上限 200，非法枚举返回 422，跨存档俱乐部返回 404。
7. 报价响应新增 `learning_adjustment`，未应用时明确说明原因。

## 4. 非测试环境验证

- 全量 `pytest -q`、`npm run build`、Playwright 全量。
- Windows `.NET` Live Reader 测试（未修改 .NET 代码，仅回归）。
- 真实数据副本：`sqlite3.backup` + `alembic upgrade head` + 单轮学习，结果见 `V3.3.2_08_REAL_FM27_ACCEPTANCE.md`。
- 性能：1k / 10k / 60k，见 `V3.3.2_08_PERFORMANCE.md`。

## 5. 不覆盖与原因

- 游戏内报价/还价：数据源不存在，标 `BLOCKED_BY_REAL_DATA`。
- 预算：不可读，不做默认假设。
- 真实成交学习：验收数据 0 笔转会，无法验证。
