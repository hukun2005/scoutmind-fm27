- 数据源审计：`docs/reports/V3.3.2_05_TRANSFER_SOURCE_AUDIT.md`
- 结论：**本版本没有新增任何"自动历史转会"来源**；在可自动读取的合同/挂牌字段上完成采集与状态历史，历史转会与成交费用继续走既有 CSV/JSON 导入通道。

| 俱乐部预算 | **否** | 无来源字段，接口固定返回 `available=false` |

## 2. 本版本改动

1. **新增 `transfer_status_history`**：一笔转会从 `agreed` → `completed`/`cancelled` 时追加状态记录，不覆盖旧状态；唯一键 `(transfer_id, new_status, changed_at)` 防重复。
2. **扩展 `transfer_fee_components`**：新增条款级 `source`、`confidence`、`payment_schedule`（nullable）。
3. **扩展 `loan_records`**：新增 `loan_fee`、工资承担金额/比例、买断选择权/强制买断费用、`option_status`、`confidence`（nullable）。
4. 采集链路本身复用 `ScanImporter` 与既有导入器，**未改协议、未改已发布 migration、未新增重复表**。
5. 合同数据不做物化复制：`player_snapshots` 的 `wage/contract_end` 就是合同观测，读取时取最新快照。

## 3. 同步与一致性

- 所有实体带 `fm_save_id`；写入与读取均校验存档归属。
- 重复导入：`ScanImporter` 既有去重规则继续生效；状态历史仅在状态变化时追加。
- 未知值：字段保持 `NULL`，接口输出 `missing_fields`，界面显示"未知/数据源不提供"，不以 0 代替。
- 真实存档存在 185 条未处理身份冲突（`identity_conflicts`），概览页直接暴露，不隐藏。
