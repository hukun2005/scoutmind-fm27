# V3.2.5 Worker 数据模型与 API 报告（Phase 4）

**状态：NOT_RUN（未实现）**

## 1. 现状核对

`backend/app` 全目录检索不到 worker / lease / heartbeat / cancel 相关实现；
`import_jobs` 表没有 `total/processed/stage/lease/retry` 之类字段。

已有能力（V3.2.3–V3.2.4）：

- `POST /api/v1/imports/scan` 同步导入，但已通过 `asyncio.to_thread` 移出事件循环；
- `GET /api/v1/imports`、`GET /api/v1/imports/{id}`；
- 同一 save+scan 重复上传幂等（`duplicate=true`）；
- 导入进行中返回 `409 import_in_progress`；
- 启动时把遗留 `running` 任务标为 `failed` 并写 `interrupted` 行。

## 2. 本轮没有实现的原因

1. 现有导入是**单事务**：行级进度无法从另一个连接写入（SQLite 写锁），要真进度必须改成批量提交，
   这会改变“失败不留半份数据”的保证，需要重新设计恢复语义与幂等；
2. 任务书要求“先审查已有任务框架，不得增加重复队列”；项目没有现成持久化队列；
3. 不做“只在测试里 202、真实仍同步”的伪 Worker。
