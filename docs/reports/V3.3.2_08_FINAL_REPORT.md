## 3. 关键边界（如实标注）

1. **原生 Live Reader 不提供转会历史**：扫描结果 `transfers=[]`，覆盖率显式为 false。没有导入文件就没有成交学习。
2. **报价/还价没有游戏内来源**：只能来自用户确认的谈判记录，事件标记 `user_confirmed`。
3. **俱乐部变化不等于转会**：只记录为 `CLUB_CHANGE_OBSERVED / UNVERIFIED`，不推断费用。
4. **预算不可读**：不默认预算充足，报价不承诺预算可行性。
5. **币种未知不默认 EUR**：只使用 `currency_original`；缺失时为空并明确提示。
6. **合成数据不入正式学习库**：`synthetic/demo/fixture` 来源直接跳过。

## 4. 真实数据验收摘要
