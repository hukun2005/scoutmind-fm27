# V3.3.1 可视化数据映射

## 1. 总览

| 图表 | 位置 | 数据来源 | 新增接口 |
| --- | --- | --- | --- |
| 阵容位置热力图 | 阵容分析 | `GET /squad/depth` + 现有 `roster` | 否 |
| 球员属性雷达 | 球员详情 | `GET /players/{id}` 的 `attributes` | 否 |
| 成长趋势 | 球员详情 | `GET /players/{id}/history` | 否（V3.3.0 已有） |
| 年龄结构 | 首页 / 阵容 | `GET /squad/overview` | 否（V3.3.0 已有） |
| 价值散点 | 球员中心 | `GET /visualizations/value-scatter` | 是 |
| 转会资金流向 | 转会情报 | `GET /visualizations/transfer-flow` | 是 |

统一由 `ChartCard` / `SectionCard` 包裹，具备加载、空、错误、脚注状态；颜色来自 `CHART_COLORS`，不引入新图表库。

## 2. 阵容位置热力图

- 数据：`items[] {slot, slot_name, count, required, coverage, status, players[]}`；`players[]` 含 `ca` 与 `name`。
- 展示：10 个位置格子（矩阵布局），每格显示人数/需求、主力、替补、状态。
- 口径：
  - 主力 = 该位置 `players` 中 CA 最高者（后端已排序）；
  - 替补 = 第二人；
  - 缺失 CA 显示「—」，不参与比较；
  - 颜色：`count == 0` 红、`count < required` 黄、其余绿。
- 交互：点击格子跳转 `/players?position_group=GK|DF|MF|FW`，查看该区域球员。
- 空状态：没有位置数据时引导指定「我的俱乐部」并导入扫描。

## 3. 球员属性雷达

- 数据：`attributes[] {name, category, value}`；`value` 为 1–20。
- 计算：按类别求非空值的算术平均；少于 3 个可用类别不绘制。
- 声明：类别均值仅为结构展示，不是 CA/PA，也不是综合评分。
- 对比页规则更严格：只保留所有已选球员都有数据的类别，避免用 0 补齐。

## 4. 成长趋势与年龄结构

- 复用 V3.3.0 的 `buildGrowthChart`、`buildAgeDistribution`，不修改业务算法。
- 成长趋势只使用真实快照点；没有多期快照时保持空状态，不伪造历史。
- 年龄结构来自后端 `age_structure.buckets`，缺失年龄不归入任何桶。

## 5. 价值散点

### 5.1 接口

`GET /api/v1/visualizations/value-scatter?save_id=&club_id=&limit=`

- `limit` 1–800，默认 400；按身价降序截断。
- 返回 `points`、`total`、`with_value`、`returned`、`note`。

### 5.2 口径

- 只包含 `market_value IS NOT NULL` 的球员；缺失身价不入图、不补 0。
- `x = 年龄`，`y = 身价（万 €）`。
- 点大小与颜色按 CA 分档：≥160 青色、≥135 蓝色、其余紫色；CA 缺失使用灰色小点。
- 点击点跳转球员详情。
- 脚注显示总数、有身价人数、实际绘制点数与截断说明。

### 5.3 限制

- 超过 800 人时只绘制身价最高的 800 人，避免浏览器卡顿；这是展示采样，不是数据截断。
- 不支持多币种换算；身价字段按存档原始币种展示。

## 6. 转会资金流向

### 6.1 接口

`GET /api/v1/visualizations/transfer-flow?save_id=&club_id=&from_date=&to_date=`

- 缺省 `club_id` 时使用「我的俱乐部」；没有标记时返回 `club: null` 与说明。
- 返回按币种分组的 `currencies[]` 与 `excluded` 计数。

### 6.2 口径（硬约束）

| 规则 | 实现 |
| --- | --- |
| 只统计成交 | `status == "completed"` |
| 未完成 | `pending / future / cancelled / failed` 只计数，不计金额 |
| 租借 | `transfer_type == "loan"` 的 `loan_fee` 单列，不并入买卖总额 |
| 自由转会 | `free / end_of_contract` 只计数，不产生费用 |
| 附加条款 | `addons_potential` 不计入已支付 |
| 费用缺失 | 只计入 `unknown_fee`，不按 0 |
| 币种 | 不同 `currency` 永不合并，各自一张图 |
| 扫描数据租借费 | 优先 `transfer.loan_fee`，为空时读取 `fee_components` 中 `loan_fee` |

### 6.3 展示

- 每个币种一张 `ChartCard`，标题「资金流向 · EUR」，单位为万。
- 柱：买入支出、卖出收入、租借收入、租借支出、净支出。
- 脚注：各类型笔数、费用未知笔数、未计入状态；区块底部展示口径说明。
- 多币种时使用自适应网格，避免同图混币。

## 7. 空数据与缺失值

- 图表为空时显示明确原因，不渲染 0 值假图。
- 单字段缺失在提示框与对比表中显示「—」。
- 接口失败显示 `ErrorState` 与重试，不静默降级。
