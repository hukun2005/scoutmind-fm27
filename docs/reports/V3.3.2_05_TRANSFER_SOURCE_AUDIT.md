## 5. 对 V3.3.2-05 实现的约束

1. **可以自动采集**：球员身份、俱乐部、周薪、合同到期、CA/PA、身价、挂牌/可租标记、已达成转会（有则记录为 `agreed`，不计入成交）。
2. **不可自动采集**：历史转会、成交费用、租借费用、买断/强制买断、分期、二转分成、预算、传闻。这些字段一律保持 `NULL` 或 `UNKNOWN`，界面上显式标注"当前数据源不提供"。
3. **复用既有能力**：`transfer_history` + `transfer_fee_components` + `LoanRecord` + `PlayerAvailability` + `PlayerSnapshot` + `estimate_value()` + `/transfers/*` 接口；不新建重复表。
4. **估价不等于成交价**：`estimate_value()` 在样本不足时拒绝给区间，报价引擎只做确定性规则计算，AI 只做解释。
5. **谈判记录只能来自用户确认或导入文件**，不得从内存读取推断"已接受/已拒绝"。
6. **真实验收**：存档 2 无转会记录，因此真实数据验收对"自动历史转会"只能是 `BLOCKED_BY_SOURCE`；对合同/工资/挂牌可做真实验收。
