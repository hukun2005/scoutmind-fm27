## 4. 偏差说明

1. **单 PR 代替三 PR**：任务书建议 A/B/C 三个 Agent、三个 PR。共享文件（`App.vue`、`router/index.ts`、`utils/chart.ts`、`types/players.ts`）由一个执行者按 B→A→C 顺序修改，采用 1 个集成分支和 1 个 PR，避免并行冲突；功能提交按后端/前端拆分。
2. **提交粒度**：原计划 A/B/C 三个功能提交，实际为后端、前端各 1 个提交。原因同上，前端三类功能共享组件与路由。
3. **球员对比未接关注名单入口**：关注名单页与球员中心已支持对比入口，关注名单行内按钮本轮未加；属于小范围缺口，可后续补充。
4. **位置热力图使用矩阵布局**：任务书允许 ECharts Heatmap 或矩阵布局；选择 HTML 矩阵以同时展示人数、主力和替补，信息密度更高。
5. **转会搜索跳列表**：转会无独立详情页，跳转 `/transfers?query=...`；俱乐部跳 `/players?club_id=...`。

## 5. 风险与回滚

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 真实存档字段分布与测试库不同 | 图表空点、对比缺失 | 所有缺失字段有「暂无数据」路径；上线前做真实存档联调 |
| 搜索 `LIKE` 在大存档上变慢 | 搜索延迟 | 已有存档过滤与结果上限；后续可加姓名索引/前缀匹配 |
| 对比按人请求详情（最多 4 次） | 弱网下加载慢 | 并行请求、单卡失败不影响其他球员 |
| 资金流向依赖「我的俱乐部」 | 无主队时无图 | 返回说明并引导设置 |
| ECharts 全量包较大 | 首屏体积 | 既有实现，未在本次扩大；后续可改按需引入 |

回滚：PR 未合并前直接关闭；合并后如需回滚，revert 集成分支对应提交即可，无数据库迁移与结构变更。
