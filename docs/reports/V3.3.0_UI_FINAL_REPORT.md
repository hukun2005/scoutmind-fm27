## 3. 页面改造情况

### 球员中心（重点）

- 顶部：`球员中心` + 「寻找优秀球员，发现潜力新星。」+ 刷新。
- 搜索：`输入球员姓名` 大号输入框；常用筛选 = 位置 / 年龄区间 / 俱乐部 / 潜力上限；
  「更多筛选」折叠 = 当前能力下限 / 位置组 / 身价上限（万） / 只看关注名单 / 数据完整度。
- 统计：球员总数、已关注球员（后端 `watchlist_only` 真实计数）。**没有实现「潜力新星」**，
  因为接口不支持 `min_pa`，按任务书要求隐藏而不是硬编码。
- 列表：7 列（球员 / 年龄 / 位置 / 俱乐部 / 当前能力 / 潜力 / 身价）；分页、排序、筛选仍是服务端执行。
- 空状态四种：加载中（骨架屏）、加载失败（错误 + 重试）、库为空（「还没有球员数据」+「同步游戏数据」→
  `/data`）、筛选无结果（「没有找到符合条件的球员」+「清除筛选条件」）。

### 首页

- 欢迎区：欢迎语、存档名、俱乐部、连接状态、游戏版本、最近导入时间；右侧「同步游戏数据 / 刷新」。
- 4 个指标：一线队人数、平均年龄、主要短板、合同需要关注（缺失显示 —）。
- 重点关注（≤4 条，来自后端短板 / 合同 / 接班 / 提醒）+ 值得关注的球员（身价前 5）。
- 最近转会动态（真实 `/transfers` 前 5）+ 5 个快捷入口。
- 趋势、年龄、雷达、位置、覆盖度、费用分布、导入记录、统计口径全部收进「更多数据洞察」折叠区，能力未删除。
- 无数据时显示「还没有球队数据」+ 同步入口。

### 其他页面

- 阵容分析 / 引援中心 / 转会情报 / 球员发展 / 表现分析 / AI 体育总监 / 角色球探 / 关注名单：
  统一中文标题 + 一句通俗说明，去掉英文眉标与实现细节；业务算法、接口与字段未改动。
- 球员详情：标题与说明中文；档案速览用「合同到期」替换内部字段「最新快照 ID」；其余分区保留。
- 待确认球员：标题与空状态改为「待确认球员 / 暂无待确认球员」。
- 数据中心：沿用数据引擎工作流实现的同步 / 导入 / 状态面板，本工作流补齐前端类型与 API 契约，避免重复实现。

### 系统设置（新增）

- 软件版本、游戏连接（来自 `/data-hub/status`）、数据存储位置（桌面版真实数据目录，浏览器模式说明）、
  备份与恢复（只陈述真实方式，无假按钮）、外观（深色固定 + 动效开关）、更新信息（无假检查按钮）、关于。
- `开发者选项（内部配置）` 默认折叠：接口令牌、诊断入口、服务地址。
- 桌面端：通过 `window.scoutmindDesktop.getInfo()` 读取版本 / 数据目录 / 日志目录，浏览器中静默降级。
