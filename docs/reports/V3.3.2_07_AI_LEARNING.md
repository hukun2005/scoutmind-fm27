## 2. 案例标准化（B-01）

每个案例统一携带：

- 标识与作用域：`case_id`、`save_id`、`player_instance_id`
- 交易事实：`transfer_type`、`deal_result`、`actual_fee`、`currency`、`installments`、`addons`、`loan_terms`、`sell_on_clause`
- 数据来源：`data_source`、`case_origin`（`imported` / `negotiation` / `demo`）、`observed_at`
- 可统计性：`usable_for_stats`（成交金额必须存在且 > 0）

边界：

- `pending` / `agreed` 等未完成交易不进入案例集；
- 演示数据标记为 `demo`，不得作为真实 FM27 策略证据；
- 跨存档严格隔离，学习状态只统计当前存档。

## 3. 相似匹配与置信度（B-02）

- 权重集中为 `SIMILARITY_WEIGHTS`，测试锁定默认值并验证可配置；
- 缺失维度不参与归一化，避免“只有位置相同”被放大为高相似；
- 匹配度低于 50 不视为相似案例，不进入报价调整层；
- 置信度分级：

| 样本数 | 等级 | 文案 |
| --- | --- | --- |
| 0 | none | 无可用案例 |
| 1–2 | insufficient | 样本不足，仅展示案例 |
| 3–4 | preliminary | 初步策略 |
| 5–9 | limited | 有限参考 |
| 10+ | stable | 可进行更稳定的统计分析 |

- 分布统计：成交金额区间（<500 万 / 500–1500 万 / 1500–4000 万 / 4000 万+）与 P25/P50/P75 分位；
  成交年龄区间（18–21 / 22–25 / 26–29 / 30+）。所有模式均返回 `sample_size`，不足 3 条时只展示不归纳。

## 4. 俱乐部画像（B-03）

- 按 `from_club_id` / `to_club_id` 拆分卖出与买入；
- 统计完成数、租借、自由转会、分期、附加条款、买断案例；
- 模式包含租借倾向、分期使用、附加条款、自由转会、出售年轻球员、合同到期前出售；
- 样本 < 3 时 `available=false`、`patterns=[]`、`message="暂无足够数据"`。

## 5. 反馈与持续学习（B-08）

- 支持 5 种结果：`completed / rejected / cancelled / negotiating / unknown`；
- 只有 `completed` + 有效金额才派生 `TransferNegotiation(status=COMPLETED)` 成交案例；
- `dedupe_key = sha256(save|instance|direction|outcome|amount|note)`，重复提交返回 `duplicate=true`，
  数据库唯一约束兜底并发；
- 写入后清空查询缓存，`learning_status.data_version` 必然变化；
- 反馈按存档校验，跨存档实例返回 404。

## 6. 真实数据限制

真实 FM27 样本（62,229 名球员）**没有历史转会与成交金额**（数据源不提供），因此：

- `learning_status.available=false`，案例数 0；
- 报价 `strategy_adjustment.applied=false`，不会伪造“已学习”效果；
- 以上部分标记为 **BLOCKED_BY_REAL_DATA**，详见 `V3.3.2_07_REAL_FM27_ACCEPTANCE.md`。
