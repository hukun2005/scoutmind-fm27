## 4. 新标签语义规范

四类标签与六种语义色（`frontend/src/utils/tags.ts`）：

| 分类 | 用途 | 示例 |
|---|---|---|
| `business` | 有真实业务依据的球员 / 关注 / 机会标签 | 重点关注、引援目标、可出售 |
| `runtime` | 真实运行状态 | 正在同步、已同步、正在扫描、排队中 |
| `risk` | 风险与需要用户行动 | 合同风险、需要你确认、身份冲突、未读 |
| `internal` | 内部技术信息，默认不渲染 | 扫描编号、源指纹、数据库版本 |

| 语义 | 深色界面 | Premium Light 界面 |
|---|---|---|
| 成功 / 正常 `success` | 低饱和绿底 + `#6ee7b7` | `#ecfdf3` / `#15803d` |
| 信息 / 普通 `info` | 低饱和蓝底 + `#93c5fd` | `#eff6ff` / `#1d4ed8` |
| 提醒 / 待处理 `warning` | 低饱和琥珀底 + `#fcd34d` | `#fffbeb` / `#b45309` |
| 错误 / 严重 `danger` | 低饱和红底 + `#fda4af` | `#fef2f2` / `#b91c1c` |
| 一般分类 `neutral` | 中性灰底 + `#cbd5e1` | `#f1f5f9` / `#475569` |
| 品牌强调 `brand` | 蓝色低饱和底 + `#a8c4ff` | `#eef2ff` / `#3730a3` |

规则：
- 标签始终带文字，颜色只做辅助（不通过颜色单独表达状态）。
- 同一状态全局同名同色；未知自由文本原样保留为中性色，不丢失用户输入。
- 长标签 `max-width: 100%` + 省略号 + `title`，不撑破表格。
- 普通界面每个球员默认只保留最关键标签；内部标签需 `allow-internal` 才会渲染。

## 6. 品牌设计说明

**方向**：Premium Light + Professional Football Intelligence。

**标识构成**：
- 抽象几何 **S**：由顶横、左半圆、中横、右半圆、底横构成一条连续等宽笔画，圆角端点，强调专业与秩序。
- **数据节点**：中横上的青色圆点，表达球探数据与 AI 决策节点。
- **应用图标底板**：深蓝 `#0B1B33` 圆角方形（22% 圆角），内嵌 12% 白色细描边，白色 S，青色节点 `#22D3EE`。
- 不使用盾牌模板、足球纹理、复杂渐变，小尺寸仍可识别；与知名品牌无高度相似。

**颜色**：深蓝 `#0B1B33`、品牌蓝 `#2563EB`、青色 `#22D3EE`、白色反色；浅色背景使用深蓝 S，深色背景使用白色 S。

**单一几何源**：所有 SVG / PNG / ICO 由 `tools/brand/generate_brand_assets.py` 的同一组坐标导出，SVG 路径为
`M174 64H108A34 34 0 0 0 108 132H148A34 34 0 0 1 148 200H82`，避免不同版本形状不一致。
