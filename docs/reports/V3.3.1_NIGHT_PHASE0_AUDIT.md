## 3. 真实缺口（本次实现范围）

1. 关注名单只有单一默认名单，没有「关注状态」、搜索与跨名单移动。
2. AI 回答没有可跳转/可关注的球员卡片；无法清空当前会话；快捷问题与任务书不一致。
3. 引援结果没有推荐等级与覆盖度说明，也没有收藏/详情按钮。
4. 球员详情缺少个人备注编辑、加入对比、生成报告；快速切换球员时缺少过期响应保护。
5. 阵容分析缺少「补强优先级」行动区与进入引援页的入口。
6. 没有 V3.3.1 性能基准脚本与前后对比数据。

## 4. 约束与风险

- 缺失字段一律 `None` → 前端显示「暂无数据」，不补 0。
- 球员身份全部使用 `PlayerInstance.id`，不以姓名关联。
- 关注名单按 `fm_save_id` 隔离；导入流程只 upsert 实例，不删除实例，因此备注/状态不会被导入覆盖。
- 只新增 migration `e2b5c8d1f3a7`，不修改历史 migration。
- PR #23 仍在评审中；本分支包含其提交，最终 PR 会注明依赖关系，不自动合并 main。
