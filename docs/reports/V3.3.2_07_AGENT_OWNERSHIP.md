# V3.3.2-07 Agent 文件所有权

本阶段由单个主控 Agent 串行执行（避免并行写同一文件产生冲突）。下表是逻辑分工与文件边界，若未来拆分并行 Agent，必须按此表隔离。

## Agent 0：主控与架构审核

职责：仓库审计、依赖与契约协调、合并冲突检查、测试结果审核、最终报告。

文件范围：`docs/reports/**`、`backend/alembic/versions/**`（仅新增）、`backend/app/main.py`（仅注册新路由）。

## Agent 1：用户体验与首次启动

- `frontend/src/components/EmptyState.vue`（仅新增可选 props，不破坏既有调用）

- `frontend/src/App.vue`（挂载引导 + 导航分组收敛）

## Agent 2：数据中心与后台任务体验

## 共享文件与串行规则

| 文件 | 归属 | 规则 |
| --- | --- | --- |
| `backend/app/models.py` | Agent 0 | 只有 Agent 0 可加 `TransferFeedback` |
| `backend/alembic/versions/*` | Agent 0 | 只新增一个迁移 |
| `backend/app/main.py` | Agent 0 | 只注册 `routes_system.router` |
| `backend/app/api/routes_transfer_director.py` | Agent 4 主编，Agent 2 只改扫描序列化 | 先由 Agent 2 提交扫描字段，再由 Agent 4 追加报价/反馈路由 |
| `frontend/src/api/transferDirector.ts` | Agent 2 建类型，Agent 5 只读使用 | 一次性写入，避免双写 |
| `frontend/src/App.vue` | Agent 1 | 其他 Agent 不改 |

6. Phase 5 反馈（`/feedback`、`/learning-status`、前端工作台）。
