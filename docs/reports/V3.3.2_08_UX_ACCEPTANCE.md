# V3.3.2-08 UX 验收（在线学习面板）

日期：2026-11-27
范围：AI 转会总监 → 成交策略 → 在线持续学习卡片。

## 1. 展示内容

| 区域 | 展示 | 数据来源 | 说明 |
|---|---|---|---|
| 状态 | “正在监视转会市场 / 自动学习已暂停”等 | `GET /transfer-learning/status` | 不显示内部枚举 |
| 计数 | 已观察事件、已确认交易、全球俱乐部、重点俱乐部 | 同上 | 0 值如实显示 |
| 时间 | 最近监控、最近学习 | 同上 | 时间格式化，不显示原始时间戳 |
| 来源限制 | “原生读取器不提供转会历史……” | `coverage.note` | 无真实转会时明确说明，不伪造进度 |
| 重点俱乐部 | 名称、买入/卖出/租借笔数、置信度与样本量 | `GET /transfer-learning/focus-clubs` | 最多 6 条 |
| 最近动态 | 真实事件生成的短句与时间 | `GET /transfer-learning/activity` | 最多 6 条，单轮上限 200 |
| 操作 | 刷新、暂停、恢复 | `POST /pause`、`POST /resume` | 不提供轮询频率、阈值、权重等开发参数 |

## 2. 交互

- 页面打开时只读取状态，**不启动学习**；学习由导入完成、用户反馈或显式恢复触发。
- 暂停只停止后续自动学习，不清空事件、画像和学习动态。
- 恢复后若存在未处理数据才创建后台任务，避免空转。
- 错误以可读提示展示；不显示堆栈、SQL 或内部错误码。

## 4. 已知限制

- 手机窄屏沿用既有响应式规则；本次未新增横向滚动区域。
