## 数据源不可得（不实现、只标注）

- 存档货币设置：`FmSave` 无字段，只能从导入转会的 `currency_original` 推导。
- 俱乐部预算 / 工资预算：无来源，始终标记未知。
- 自动读取游戏内历史转会 / 合同条款：无来源。
- 球员俱乐部 UID：上游缺失时永久 `MISSING_SOURCE_FIELD`。
