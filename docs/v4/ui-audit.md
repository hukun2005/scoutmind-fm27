## 2. 导航映射（旧 → 新）

旧分组：总览 / 球探分析（10 项）/ 数据管理（6 项）/ 工具（2 项），共 19 个一级入口。

新分组：总览 / 球探工作台（6）/ 转会中心（2）/ 智能总监（3）/ 游戏管理（2）/ 高级工具（折叠，4），主菜单 14 项，高频任务集中在三组内。

- 「球员中心」→「球员探索」
- 「引援中心」→「引援机会」
- 「数据中心」→「游戏数据」
- 「存档身份」→「存档管理」
- 数据治理、身份复核、身份中心、待确认球员、角色球探不再出现在默认菜单，统一收进「高级工具」折叠区；路由与能力保留。
- 所有路由路径不变，存档隔离与既有 API 不变。

## 3. 设计系统现状

已有 `frontend/src/styles/tokens.css` 提供深色语义令牌、间距、字体、圆角、阴影与动效；已有通用组件：
`PageHeader`、`SectionCard`、`KpiCard`、`DataTable`、`ChartCard`、`EmptyState`、`ErrorState`、`LoadingBlock`、`FilterPanel`、`ConfidenceTag`、`CoverageBar`、`StatHeader`、`GlobalSearch`。

V4.0 不另起一套皮肤，而是在现有令牌上做三件事：
1. 统一页面层级：页面标题 → 结论/指标 → 风险与机会 → 详细数据 → 高级分析。
2. 新增「AI 简报 / 诊断」表达组件样式（规则生成，明确标注依据与推测边界）。
3. 收敛卡片数量：同层信息合并，图表默认折叠或下移。

## 4. 明确不做

- 不新增 Evidence & Trust Center、Interactive Tactical Pitch。
- 不修改后端 API 契约、数据库结构与存档隔离。
- 不以假数据填充；未知值继续显示 `—` 或「未知」，不记为 0。
- AI 简报只使用当前真实字段，并在界面标注「规则生成」。
