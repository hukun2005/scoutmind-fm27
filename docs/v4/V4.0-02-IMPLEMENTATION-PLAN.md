## 2. 信息架构与导航

沿用 V4.0-01 已交付结构（总览 / 球探工作台 / 转会中心 / 智能总监 / 游戏管理 / 高级工具折叠），本次不改路由、不改菜单分组、不新增入口。

页面内统一层级（所有改造页面遵守）：

1. 页面标题（`PageHeader`）+ 当前存档/数据时间等元信息
2. **结论层**（`InsightPanel`：结论 + 依据 + 风险/缺口，标注“规则生成”或“数据事实”）
3. **关键指标**（`StatStrip`：紧凑、非卡片堆叠、缺失显示 `—`）
4. **主任务区**（结果列表 / 事件 / 报告 / 同步状态）
5. **详细分析**（图表、属性、历史、诊断；次要内容折叠）

## 3. 设计系统（在既有 tokens 上扩展，不换肤）

新增两个共享组件，全部页面复用：

- `components/InsightPanel.vue`：结论面板。`title`、`subtitle`、`tone`（`info`/`success`/`warning`/`danger`/`neutral`）、`items[{ label, text, tone? }]`、`footnote`；默认左缘 3px 状态色、无多层描边。
- `components/StatStrip.vue`：紧凑指标条。`items[{ label, value, hint?, tone? }]`，分隔线而非独立卡片。

视觉纪律：

- 页面背景沿用 `--sm-bg-primary`；层级用明度与间距，不给每个区块加重边框。
- 卡片只用于“可交互对象”（球员机会卡、事件卡、俱乐部画像）；静态指标用 `StatStrip`。
- 强调色仅用于结论、当前状态与小面积高亮；风险 `--sm-danger`、警告 `--sm-warn`、成功 `--sm-success`。
- 标题层级固定：`h1` 页面（28px）→ `h2` 区块（14px 600）→ 小标签（11px，`sm-label`）。
- 关键数字使用 `sm-num` + 600 字重；辅助文字使用 `--sm-text-2/3`。
- 图表默认高度 ≤ 280px，放在详情区或折叠区；不新增装饰性图表。
- 空值一律 `—` 或「未知/暂无数据」，禁止用 0 代替；空状态必须说明原因 + 下一步动作。

## 4. 数据与规则边界（硬约束）

- 不新增/不删除后端 API；不修改 `src/api/*`、`src/types/*`、数据库、存档隔离、自动修复、Agent 工具。
- 不伪造字段：结论只能由页面已获取的数据推导，或在无数据时明确写“数据不足”。
- AI 解释与策略建议可以展示；报价金额只显示既有确定性引擎结果，前端不做金额推断。
- 不向普通用户暴露内部节点名、原始 JSON、堆栈；技术诊断折叠在“高级信息”。
- 重要写操作（切换存档、生成/保存方案、修改关注）保留确认或现有二次语义，只读分析不频繁打断。
