# ScoutMind FM27 V3.2.9.2 — 系统要求

## 运行 ScoutMind（发布包）

| 项 | 最低 | 建议 |
| --- | --- | --- |
| 操作系统 | Windows 10 x64 | Windows 11 x64 |
| PowerShell | 7.0 | 7.4+ |
| Python | 3.11 | 3.13 |
| 内存 | 4 GB | 8 GB 以上（FM27 + 扫描同时运行更占内存） |
| 磁盘 | 2 GB 可用 | 10 GB 可用（扫描库与备份） |
| 网络 | 首次安装依赖需要 | — |
| 显示 | 1024×768 | 1440×900 以上 |

不需要：Node.js、.NET SDK/Runtime（发布包内的 C# 组件为自包含）。

## 运行 ScoutMind + 真实 FM27

| 项 | 要求 |
| --- | --- |
| FM27 平台 | Steam（appId 4530370） |
| FM27 版本 | 27.1.0，build `26620374`，`game_plugin.dll` `27.1.0+2505117`（已验证） |
| 进程权限 | 与 FM27 相同的用户会话；读取器只读目标进程内存 |
| 权限 | 不需要管理员权限 |

其它构建可能可以检测到，但会被版本闸门拒绝读取，直到被验证后写入 `compatibility.json`。

## 仅开发/重新构建时需要

| 项 | 版本 |
| --- | --- |
| Node.js | 22 或 24 |
| .NET SDK | 10.0 |
| PostgreSQL | 16（仅验证 PG 迁移时需要） |
