# ScoutMind FM27 V3.2.9.2 — 安全检查报告

- 检查时间：2026-11-26
- 范围：本次发布涉及的后端、前端、脚本与发布包
- 结论：未发现高危问题；无真实密钥入库；默认只监听本机

## 1. 密钥与凭据

| 检查 | 结果 |
| --- | --- |
| 仓库内 `.env` | 未跟踪（仅 `.env.example`） |
| 硬编码密码/密钥扫描（`backend/app`、`scripts`） | 未发现真实值，仅示例占位 |
| 日志中的敏感数据 | 只记录方法、路径、状态码与耗时，不记录请求体、不记录 Token |
| 发布包 | 不含 `.env`、不含数据库、不含备份 |

## 2. 网络暴露面

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 监听地址 | `127.0.0.1` | 发布脚本固定回环地址 |
| CORS | `localhost` / `127.0.0.1` 的开发端口 | 不开放任意来源 |
| API Token | 默认为空（仅本机可访问） | 设置 `SCOUTMIND_API_TOKEN` 后，除 `/api/v1/health` 外均需 `X-ScoutMind-Token` |
| 未知 API 路径 | 返回 404 JSON | 新增的前端兜底不会把 `/api/v1/*` 吞成 200 |

## 3. 路径与文件

| 检查 | 结果 |
| --- | --- |
| 新增静态文件兜底 | 解析路径后校验必须位于 `dist` 目录内，阻断 `..` 穿越（`main.py`） |
| 上传/导入路径 | 使用应用生成的相对路径，拒绝绝对路径与 `..`（既有测试覆盖） |
| 脚本下载执行 | 未使用 `Invoke-Expression` / `DownloadString` / 远程脚本 |
| 停止脚本误杀风险 | 校验 `uvicorn` + `app.main:app` + 发布包路径，不匹配则拒绝 |

## 4. 数据安全

| 项 | 结果 |
| --- | --- |
| 存档隔离 | 所有查询按 `fm_save_id` 过滤；本轮新增多存档隔离回归测试 |
| 写入安全 | 写入门次 + generation + 幂等键；过期确认被拒绝 |
| 导入幂等 | 相同 `scan_id` 重复上传返回 `duplicate=true`，不重复写入 |
| 备份 | SQLite 在线备份 API，备份后校验完整性；不修改原库 |
| 读取器 | 只读进程内存，不写游戏文件；未验证构建拒绝读取 |

## 5. 依赖

| 项 | 结果 |
| --- | --- |
| 依赖来源 | `requirements.txt` / `package-lock.json` 固定版本 |
| 发布包依赖 | 只含 Python 依赖清单，前端为已构建静态文件，无 `node_modules` |
| 未执行 | `pip-audit` / `npm audit` 本轮 NOT_RUN（未纳入本次门禁） |

## 6. 结论

- 无 BLOCKER、无高危发现；
- 2 项依赖漏洞扫描 `NOT_RUN`，已如实标注；
- 建议正式公开发布前把 `pip-audit`、`npm audit --omit=dev` 加入 CI。
