# ScoutMind FM27 V3.2.9.2 — 发布说明

- 版本：`3.2.9.2`
- 类型：First Public Preview
- 日期：2026-11-26
- 基线提交：`33882bc`（PR #14 合并后）

## 本版重点

### 1. 存档切换安全

- 切换存档后，旧存档的确认状态立即失效，不允许继续写入；
- 已确认身份绑定 generation，跨代操作被拒绝；
- 真实 FM27 A/B/A 验收通过（generation 1→2→3，两次 `invalidated=true`）。

### 2. 身份治理

- Verified 生命周期账本：确认、撤销、冲突全程可追溯；
- 审核操作加入乐观锁与幂等，重复提交不会产生双重写入；
- 同名球员候选不再被截断，完整返回；
- 转会证据关联与审核审计落库。

### 3. 性能

- 为转会、候选、采集、身份等高频查询补充索引；
- 44,144 名球员真实导入约 11 分钟，导入期间 API 保持可用。

### 4. 转会接口修复（本版新增）

- 修复 `GET /api/v1/transfers` 因未定义变量导致的 500；
- 修复 `sort` 参数被静默忽略，非法字段现在返回 `400 invalid_sort`；
- 覆盖率改为在**全量筛选结果**上计算，分页不再影响统计口径；
- 新增 13 个回归测试覆盖分页、筛选、排序、缺失费用、附加条款、多存档隔离与统计一致性。

### 5. Windows 发布工程（本版新增）

- 新增一键发布包：`ScoutMind-FM27-V3.2.9.2-Windows-x64.zip`；
- 后端同端口托管生产前端，刷新任意前端路由不会 404；
- 新增 `Start / Stop / Check-Environment / Backup-Database` 脚本；
- 停止脚本校验进程归属，不会误杀其它程序；
- 数据库备份使用 SQLite 在线备份 API 并校验完整性。

## 升级说明

- 从任何 3.2.x 版本升级：直接替换程序文件，保留 `data/` 目录；启动时自动执行迁移；
- 数据库结构变更仅追加，不删除已有数据；
- 升级前建议先执行 `Backup-Database.ps1`。

## 已知问题

见 `KNOWN_ISSUES.md`。本版不包含：云端同步、多用户、伤病预测、逐场统计（数据源不提供）。
