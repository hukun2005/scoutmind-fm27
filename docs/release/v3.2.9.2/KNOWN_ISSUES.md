# ScoutMind FM27 V3.2.9.2 — 已知问题

按影响分级。`NOT_RUN` 表示本轮未执行，不代表通过。

## 功能边界（设计如此，不是缺陷）

| 项 | 说明 |
| --- | --- |
| 转会历史 | 上游导出不含转会历史，相关模块只显示已有数据 |
| 逐场统计 | 数据源不提供，表现分析按赛季维度呈现 |
| 主执教俱乐部 | 上游 `meta.myClub` 为空时需要手动指定本队 |
| 租借/所有权 | 上游缺少 `parentClub`/`loanClub`，标记为未知，不做推断 |
| 梯队归属 | 需要额外导入阵容 CSV |
| AI 体育总监 | 使用确定性工具链；真实 LLM 联调 `NOT_RUN`（无 API Key） |

## 环境限制

## 体验相关（MINOR）

| 项 | 说明 |
| --- | --- |
| 移动端抽屉无 Focus Trap | 支持 Escape 与点击遮罩关闭；键盘 Tab 可能离开抽屉 |
| 首次启动需联网 | 后端依赖在首次启动时安装；离线机器需预置 `backend/.venv` |
| 大存档首次导入较慢 | 4 万名以上球员约 11 分钟，期间界面可用 |

## 安全说明

| 项 | 说明 |
| --- | --- |
| 默认无 API Token | 默认只监听 `127.0.0.1`；如需局域网访问必须先设置 `SCOUTMIND_API_TOKEN` |
| CORS 默认仅本机 | 默认允许 `localhost` / `127.0.0.1` 的开发端口 |
| 未知构建拒绝读取 | 未验证的 FM27 构建会被版本闸门拒绝 |
