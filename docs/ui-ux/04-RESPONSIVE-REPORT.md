## 2. 自动化验证方法

脚本：本地 Playwright（Chromium），6 种视口 × 7 个页面 = 42 个组合。
判定：`document.documentElement.scrollWidth > window.innerWidth + 1` 视为横向溢出；
同时统计 `.sm-chart` 高度 < 40px 的「零高度图表」。

视口：`1920×1080`、`1440×900`、`1366×768`、`1024×768`、`768×1024`、`390×844`。
页面：`/`、`/squad`、`/players`、`/recruitment`、`/transfers`、`/agent`、`/identity-center`。

## 5. 已知问题

1. `/transfers` 列表接口在后端返回 500：
   `backend/app/api/routes_transfers.py:111` 使用未定义变量 `all_rows`（`NameError`）。
   该文件在 `main` 上即为此状态，本次未修改后端，也不能在前端修复；
   页面按既有错误态显示 `ErrorState` 与重试入口。统计区块 `/transfers/stats` 正常。
   状态：`BLOCKED`（后端缺陷，超出 UI 分支范围）。
2. 移动抽屉无焦点陷阱（见可访问性报告 A-1）。
3. 超宽表格（转会/数据页）在 768px 以下依赖容器内横向滚动，这是既有交互约定，
   未改为卡片式列表，以免影响列语义。
