# ScoutMind FM27 — Dashboard 设计（Phase 3）

`/` 从「若干卡片」重构为 **智能指挥中心**：先回答「我现在处在什么状态」，
再回答「球队强在哪、缺在哪、下一步做什么」。

## 1. 信息架构

```
┌ 指挥条 Command ─────────────────────────────────────────────┐
│ COMMAND CENTER · 欢迎语 · 数据口径说明                      │
│ 芯片：存档 / 游戏版本 / 数据来源 / 最近导入 / 本队           │
│ 操作：导入扫描数据 · 打开 AI 体育总监 · 刷新                 │
├ KPI 行（6）─────────────────────────────────────────────────┤
│ 阵容规模 · 阵容评分 · 平均年龄 · CA 均值 · 阵容总身价 · 未读提醒 │
├ 球队实力趋势（2fr）────────────┬ AI 事实摘要（1fr）──────────┤
│ 总身价 + CA 均值双轴折线        │ 规则推导的 0–4 条事实        │
├ 阵容年龄分布（2fr）────────────┬ 阵容能力雷达（1fr）──────────┤
├ 位置结构（2fr）────────────────┬ 球员价值 Top 5（1fr）────────┤
├ 数据覆盖度（2fr）──────────────┬ 成交费用分布（1fr）──────────┤
├ 最近活动（2fr）────────────────┬ 快速入口（1fr）──────────────┤
└ 口径说明 ──────────────────────────────────────────────────┘
```

## 3. AI 事实摘要：只做确定性推导

标题下明确写「规则推导，非 LLM 生成」，页脚再次提示。规则仅使用后端已有字段：

1. `weakness[0]` → 「位置短板：{位置}」+ 现有人数 / 需求人数 / 后端建议。
2. `contracts.at_risk_count > 0` → 「合同风险：N 名球员」+ 前 3 个姓名。
3. `coverage` 中 `< 0.6` 的字段 → 「数据缺口：N 个字段低于 60%」。
4. `succession[0]` → 「接班规划：球员」+ 后端 `verdict`。
5. `alerts > 0` → 「未读提醒：N」。

上限 4 条，每条可跳到对应页面。**不生成任何后端没有的结论、分数或建议**。
没有本队或没有可推导事实时，显示空状态并指向「阵容智能 / 数据中心」。

## 4. 状态设计

| 状态 | 表现 |
| --- | --- |
| 首次加载 | KPI 骨架、图表卡骨架、AI 摘要骨架 |
| 无本队 | 年龄/雷达/位置图显示「未指定本队」，提供「去指定本队」按钮；KPI 显示 `—` 且 hint 为「未指定本队」 |
| 无扫描数据 | 趋势/费用/覆盖度空状态，说明需要导入扫描 |
| 接口失败 | `ErrorState` + 重试；不影响其它已加载区块 |
| 演示数据 | 顶部 `DemoBanner` 常驻（可本标签页关闭），指挥条出现「演示数据」芯片 |
| 后端未配置 LLM | 外壳脚注显示「确定性模式」；AI 摘要不受影响 |

## 5. 视觉规则

- 指挥条是唯一的大面积渐变 + 网格 + 光晕区域。
- KPI 行 6 张卡等宽自适应（`minmax(172px, 1fr)`），顶部 2px 色条区分语义。
- 图表卡标题前有渐变竖条；图例统一底部居中。
- 价值 Top 5 的横条宽度仅表示「相对本列表最大值的比例」，不代表官方评分。
- 悬停抬升与光晕只出现在可点击卡片；不可点击图表卡保持静置。

## 6. 响应式

| 宽度 | 布局 |
| --- | --- |
| ≥ 1180px | 2fr + 1fr 双列 |
| 900–1179px | 单列堆叠，KPI 自动 3–4 列 |
| ≤ 900px | 侧栏抽屉；指挥条纵向排列，操作按钮换行 |
| ≤ 640px | 页面内边距 12–16px；KPI 2 列；指挥条标题 28px；按钮等分 |

实测：1920 / 1440 / 1366 / 1024 / 768 / 390 均无横向溢出（见 `04-RESPONSIVE-REPORT.md`）。

## 7. 刻意不做

- 不展示虚构的「AI 推荐引援」名单；推荐需要后端工具与样本，页面只提供入口。
- 不把 `null` 当 0 画进图表。
- 不合并或重命名任何原有指标口径。
