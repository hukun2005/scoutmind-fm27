## 2. 焦点与键盘

| 项目 | 实现 |
| --- | --- |
| 全局焦点 | `:focus-visible` 2px `#22d3ee` + 2px offset |
| 跳转链接 | 首个 DOM 元素「跳到主内容」，聚焦时从顶部滑入 |
| 侧栏 | `aria-label="主导航栏"`，当前项 `aria-current="page"` |
| 移动抽屉 | 汉堡按钮 `aria-expanded` / `aria-controls`；`Escape` 关闭；遮罩可点击关闭 |
| 表格行 | 可点击行 `tabindex="0"`，Enter/Space 激活，行内焦点轮廓 |
| 卡片链接 | `KpiCard` 使用铺满卡片的匿名锚点，焦点环在锚点上 |
| 排序 | 表头按钮可聚焦，`aria-sort` 同步 ascending/descending/none |
| 图标按钮 | 全部带 `aria-label` + `title`（刷新、提醒、设置、汉堡） |

## 3. 语义与状态

- 图表：`role="img"` + 中文 `aria-label`；ECharts `aria.enabled` 生成数据摘要；雷达/柱状/折线均有。
- 覆盖率：`role="progressbar"` + `aria-valuemin/max/now` + `aria-label`（含「无数据」）。
- 加载：`LoadingBlock` 为 `role="status"` + `aria-label`。
- 空/错误：文案明确说明原因与下一步；演示数据横幅可被读屏读取。
- 状态不只靠颜色：分数徽标带数值，置信度带文字，转会/合同状态保留原文标签，
  delta 同时保留 `+/-` 符号。

## 4. 动效与视觉舒适度

- 所有新动效在 `prefers-reduced-motion: reduce` 下降级：页面进入、路由切换、
  卡片抬升、状态点脉冲、刷新旋转、骨架扫光（Element 覆盖）与 ECharts 入场全部关闭或压到 1ms。
- 不使用闪烁（< 3Hz）；脉冲动画为 2.4s 低频透明度变化，不改变布局。
- 文字不被动画遮挡：页面进入仅 8px 位移，无遮罩层。

## 5. 字体与缩放

- 基准 14px，正文行高 1.55；200% 缩放下布局使用弹性网格，无固定高度文本容器
  （图表卡高度固定，但标题/图例可换行）。
- 所有金额/比例使用 `tabular-nums`，避免数字跳动。
- 中文使用 PingFang SC / 微软雅黑回退，避免系统缺字。
