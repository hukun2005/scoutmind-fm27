## 1. 身份与隔离

| 概念 | 契约 |
|---|---|
| 球员身份 | 一律使用 `player_instances.id`（存档内实例）；跨存档同名不算同一球员，禁止跨存档共享机会/报价/谈判 |
| 球员姓名/位置/年龄/身价/工资/合同 | 取 `player_instances.latest_snapshot_id` 指向的 `player_snapshots` 行；缺失即 `null`，不推算 |
| 俱乐部身份 | `clubs.id`（存档内）；真实数据仅 172 人有归属，`club_id=null` 时前端显示"俱乐部未知" |
| 存档隔离 | 所有新表/查询必须带 `fm_save_id`；服务端注入 `save_id`，拒绝模型传入的 `save_id` |
| 用户俱乐部 | `fm_saves.user_club_id`，经 `analytics.squad.user_club()` 解析 |
| 时间基准 | 合同剩余月数按该球员最新快照的 `game_date` 计算；`game_date` 缺失时回退存档内最大 `game_date`，仍缺失则不计入"合同到期"机会 |

## 2. 新增数据表（唯一新增 migration）

### 2.1 `transfer_opportunities`

当前机会快照（可重建的物化结果，不是事实源）。每个 `(save, instance, type)` 一行。

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | int PK | |
| `fm_save_id` | FK fm_saves | 存档隔离 |
| `player_instance_id` | FK player_instances | 球员实例 |
| `opportunity_type` | str(24) | `listed` / `loan_listed` / `release_listed` / `contract_expiring` / `ai_inferred` |
| `verified_status` | str(12) | `confirmed`（游戏字段直接读取）/ `inferred`（规则推测） |
| `confidence` | float? | 0–1；确认字段=1.0，推测按证据数递减 |
| `source` | str(32) | `player_availability` / `player_snapshots` / `rule:ageing` 等 |
| `first_seen_at` | datetime | 首次发现 |
| `last_seen_at` | datetime | 最近一次仍在 |
| `active` | bool | 本轮扫描仍存在；消失置 False 并写事件 |
| `is_primary` | bool | 每名球员只有一个主机会（优先级 listed > loan_listed > release_listed > contract_expiring > ai_inferred），供默认列表无重复分页 |
| `detail_json` | text | 桶位、剩余月数、信号列表、缺失字段 |
| `ability_score` / `squad_fit_score` / `opportunity_score` / `financial_score` / `overall_score` | float? | 各维度独立；无法计算保持 NULL |
| `recommendation_group` | str(16)? | `strong` / `watch` / `loan` / `long_term` / `not_recommended` |
| `score_confidence` | float? | 可用维度权重占比 × 数据置信度 |

约束：`UniqueConstraint(fm_save_id, player_instance_id, opportunity_type)`；
索引：`(fm_save_id, opportunity_type, active)`、`(fm_save_id, overall_score)`、`(fm_save_id, player_instance_id)`。

### 2.2 `transfer_opportunity_events`

状态变化历史，只追加，不更新/删除。

| 列 | 说明 |
|---|---|

| `event_type` | `discovered` / `withdrawn` / `reappeared` / `bucket_changed` / `inferred_changed` |
| `previous_value` / `new_value` | 文本化旧/新状态（如 `listed=1`、`bucket=12m`） |
| `observed_at` | 本轮扫描时间 |
| `evidence_json` | 证据 |

约束：`UniqueConstraint(fm_save_id, player_instance_id, opportunity_type, event_type, observed_at)`；
索引：`(fm_save_id, observed_at)`、`(fm_save_id, player_instance_id)`。

### 2.3 既有表扩展（`transfer_offers`）

新增 nullable 列：`loan_fee`、`wage_contribution_pct`、`buy_option_fee`、`buy_obligation_fee`、`loan_months`。
`direction` 扩展为 `buy` / `sale` / `loan`；未知金额保持 NULL。

### 2.4 不新建的表及原因

| 任务书建议实体 | 决策 | 原因 |
|---|---|---|
| `PlayerTransferIntent` | **不建表** | 真实来源无离队意愿字段；建空表会诱导界面显示"0 人想离队"。雷达以 `opportunity_type=ai_inferred` + `verified_status=inferred` 表达推测，并在 summary 返回 `unsupported_fields:["transfer_intent"]` |
| `TransferStrategyCase` | **不建表** | 案例可由 `transfer_history` + `transfer_fee_components` + `loan_records` + 已完成 `transfer_negotiations` 确定性推导；重复存储会造成两份真相 |
| `Negotiation` / `NegotiationEvent` | **复用** | 上一轮已建 `transfer_negotiations` / `negotiation_events`，状态机已实现 |
| 提醒 | **复用** `alerts` | 已有按 `(save, player, alert_type, title)` 去重 |

## 3. 机会规则（确定性，05-01）

扫描输入：最新快照 + 最新 `player_availability`（每人一行） + 用户阵容（`analytics.squad`）。

| 类型 | 规则 | 状态 |
|---|---|---|
| `listed` | `availability.listed is True` | confirmed |
| `loan_listed` | `availability.loan_listed is True` | confirmed |
| `release_listed` | `availability.set_for_release is True` | confirmed |
| `contract_expiring` | `contract_end` 与 `game_date` 均存在，剩余月数 ≤ 24；`detail.bucket` ∈ `6m/12m/24m` | confirmed（日期） |
| `ai_inferred` | 仅在俱乐部可读且该队阵容 ≥ 5 人时：①`age ≥ 31` 且合同 ≤ 24 个月 → "年龄与长期规划不匹配，可能存在出售窗口"；②`age ≤ 24` 且 `ca ≥ 队内均值 + 5` → "能力高于同队平均，可能被更大俱乐部关注" | inferred |

硬性规则：
- `listed=False` 是"已确认未挂牌"，`null` 是"来源未提供"，二者不可合并。
- 离队意愿 **没有来源**：summary 固定返回 `transfer_intent: "unsupported"`；不得由出场时间/年龄推断"想离队"。
- 同一球员可同时拥有多个类型（如 `listed` + `contract_expiring`）。
- 扫描不得每次打开页面全量重跑：`GET` 只读表；`POST /opportunities/refresh` 才重算；表为空时允许自动扫描一次。

评分（05-03，全部可解释、缺失即 NULL）：

| 维度 | 规则 |
|---|---|
| `ability_score` | `clamp((ca - 40) / 140 * 100, 0, 100)`；无 ca 为 NULL |
| `squad_fit_score` | 取 `squad_overview.depth`：`slot` 覆盖率与替补质量越低分越高（`100 * (0.6*(1-coverage) + 0.4*(1-depth_quality))`）；无阵容/位置未知为 NULL |
| `opportunity_score` | listed 85 / release 80 / loan_listed 75 / contract 6m 80、12m 65、24m 50；inferred 40；合同 ≤12 个月 +5；上限 100 |
| `financial_score` | 无预算来源 → **NULL**，并返回 `budget_known=false`；不得输出"符合预算" |
| `overall_score` | 可用维度按权重 0.35/0.25/0.25/0.15 重新归一化加权 |
| `score_confidence` | 可用权重占比 × 数据置信度（身价/工资缺失会降低） |

分组规则：`strong`（overall≥75 且 opportunity≥70）→ `loan`（loan_listed 且 overall≥55）→ `long_term`（age≤21 且 `pa-ca≥15` 且 overall≥55）→ `watch`（overall≥60）→ `not_recommended`。

## 4. 成交策略案例（05-02）

- 案例源：`transfer_history.status='completed'`（含 `transfer_type=permanent/loan/free`）+ `transfer_fee_components`（base_fee/installment/addon）+ `loan_records` + `transfer_negotiations.status='COMPLETED'`。
- 案例字段：`case_id`、`player_name`、`player_position`（由实例最新快照补）、`player_age`、`player_value`、`contract_remaining`、`from/to club`、`transfer_type`、`actual_fee`、`installments`、`addons`、`loan_terms`、`sell_on_clause`、`deal_result`、`data_source`、`confidence`、`observed_at`。
- `case_origin`：`synthetic_fixture` → `demo`；其余 → `imported`。响应必须带 `data_kind`，演示数据不得冒充真实成交。
- 相似匹配权重：位置组 30、年龄差 ≤2 / ≤4 = 20/10、身价比 ∈[0.5,2] 20、合同差 ≤12 月 15、类型匹配（目标 `loan_listed` ↔ 租借案例）15；缺失维度不计入分母。
- 样本不足（同类 < 3）时 `insufficient_sample=true`，只展示案例，不给策略结论。

## 5. 报价契约（05-04/05/06）

### 5.1 买入（已有，沿用）
三套：`conservative` / `competitive` / `fast_close`；金额由确定性引擎生成，AI 只解释。

### 5.2 租借（新增，05-05）
三套：`low_cost_loan` / `development_loan` / `loan_to_buy`。

| 方案 | 租借费 | 工资承担 | 买断 |
|---|---|---|---|
| 低成本 | 估值 × 1% | 30% | 无 |
| 发展型 | 估值 × 3% | 50% | 选择权买断 = 调整后估值 × 0.95 |
| 租借后买断 | 估值 × 5% | 70% | 强制买断 = 调整后估值 × 1.00 |

- 租期默认 12 个月；`total_committed = 租借费`；`potential_total = 租借费 + 买断费`。
- 球员未被标记 `loan_listed` 时仍可生成，但必须返回警告"游戏内未标记可租借，报价可能被拒绝"。
- 未知估值 → `available=false`，不输出金额。

### 5.3 出售（已有，沿用）
三套：`quick_sale` / `fair_sale` / `max_value`。

### 5.4 保存与版本
`POST /offers/buy|sell|loan` 生成；`POST /offers` 保存草稿；买入/出售沿用 `transfer-offer-1`，租借使用 `transfer-loan-offer-1`；同一快照+参数结果可重复。

## 9. 验收与降级

| 场景 | 期望 |
|---|---|
| 真实存档无历史成交 | 策略案例 `available=false` + "当前相似成交案例不足"，不生成案例 |
| 合同日期缺失 | 该球员不进入合同到期机会；summary 计入 `missing_contract` |
| 挂牌字段为 NULL | 不显示"未挂牌"，显示"来源未提供" |
| 第八个字段缺失 | 评分维度为 NULL，`score_confidence` 降低 |
| 切换存档 | 所有响应按 `save_id` 隔离；前端清空缓存重拉 |
| 重复刷新 | 幂等：无变化不重复写事件，不重复发提醒 |
