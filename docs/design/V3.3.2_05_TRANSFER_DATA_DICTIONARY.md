# V3.3.2-05 转会模块数据字典

- 迁移：`e7c2b9a41f60`（新增机会表、事件表，扩展报价租借字段）
- 通用规则：金额单位与存档一致（默认 EUR）；`NULL` 表示来源未提供或该方案不适用，绝不以 0 代替；所有表带 `fm_save_id` 隔离。

## 1. `transfer_opportunities`

| 列 | 类型 | 可空 | 说明 |
|---|---|---|---|
| `id` | int | 否 | 主键 |
| `fm_save_id` | int FK | 否 | 存档 |
| `player_instance_id` | int FK | 否 | 球员实例 |
| `opportunity_type` | varchar(24) | 否 | `listed` / `loan_listed` / `release_listed` / `contract_expiring` / `ai_inferred` |
| `verified_status` | varchar(12) | 否 | `confirmed`（游戏字段）/ `inferred`（规则推测） |
| `confidence` | float | 是 | 0–1；确认字段 1.0，推测 0.5 |
| `source` | varchar(32) | 否 | `player_availability` / `player_snapshots` / `rule:ageing` / `rule:ability` |
| `first_seen_at` | datetime | 否 | 首次发现（UTC） |
| `last_seen_at` | datetime | 否 | 最近一次仍存在 |
| `active` | bool | 否 | 本轮是否仍存在 |
| `is_primary` | bool | 否 | 每名球员唯一主机会，用于默认列表去重 |
| `detail_json` | text | 否 | `flags`、`contract_end`、`game_date`、`remaining_months`、`bucket`、`slot`、`signals` |
| `ability_score` | float | 是 | 0–100 |
| `squad_fit_score` | float | 是 | 0–100 |
| `opportunity_score` | float | 是 | 0–100 |
| `financial_score` | float | 是 | 当前恒为 NULL（无预算来源） |
| `overall_score` | float | 是 | 归一化加权 |
| `recommendation_group` | varchar(16) | 是 | `strong/watch/loan/long_term/not_recommended` |
| `score_confidence` | float | 是 | 0–1 |

唯一约束：`(fm_save_id, player_instance_id, opportunity_type)`。
索引：`(fm_save_id, opportunity_type, active)`、`(fm_save_id, is_primary, active)`、`(fm_save_id, overall_score)`、`(fm_save_id, player_instance_id)`。

## 2. `transfer_opportunity_events`

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | int | 主键 |
| `fm_save_id` | int FK | 存档 |
| `player_instance_id` | int FK | 球员实例 |
| `opportunity_type` | varchar(24) | 机会类型 |
| `event_type` | varchar(24) | `discovered/withdrawn/reappeared/bucket_changed/inferred_changed` |
| `previous_value` | varchar(64) | 旧状态（如 `bucket=12m`） |
| `new_value` | varchar(64) | 新状态 |
| `observed_at` | datetime | 扫描时间 |
| `evidence_json` | text | 证据 |

唯一约束：`(fm_save_id, player_instance_id, opportunity_type, event_type, observed_at)`，保证重复扫描幂等。

## 3. `transfer_offers` 新增列

| 列 | 类型 | 说明 |
|---|---|---|
| `loan_fee` | float | 租借费（建议条款） |
| `wage_contribution_pct` | float | 工资承担比例 0–100 |
| `buy_option_fee` | float | 买断选择权费用 |
| `buy_obligation_fee` | float | 强制买断费用 |
| `loan_months` | int | 租期（月） |

`direction` 现有取值：`purchase` / `sale` / `loan`。

## 4. 机会接口字段（`GET /opportunities`）

| 字段 | 说明 |
|---|---|
| `opportunity_id` / `instance_id` | 机会与球员实例 |
| `player_name` / `club_id` / `club_name` | 俱乐部可能为空（真实数据仅 172 人有归属） |
| `position` / `age` / `market_value` / `wage` | 来自最新快照，未知为 `null` |
| `contract_end` / `contract_remaining_months` / `contract_bucket` | 按球员 `game_date` 计算 |
| `listed` / `loan_listed` / `set_for_release` | `true/false/null` 三值，`null` 表示来源未提供 |
| `opportunity_type` / `verified_status` / `confidence` / `source` | 机会性质与来源 |
| `is_primary` / `types` | 是否主机会、该球员全部活跃类型 |
| `scores.{ability,squad_fit,opportunity,financial,overall,confidence}` | 评分，缺失为 `null` |
| `recommendation_group` | 推荐分组 |
| `detail` | 桶位、剩余月数、槽位、AI 信号 |
| `first_seen_at` / `last_seen_at` | 时间 |

## 5. 策略案例字段

`case_id`、`player_instance_id`、`player_name`、`player_position`、`player_age`、`player_value`、`contract_remaining`、`selling_club`、`buying_club`、`transfer_type`、`actual_fee`、`base_fee`、`effective_fee`、`addons_potential`、`installments{count,amount}`、`addons{count,amount}`、`loan_terms{loan_fee,wage_contribution_pct,has_option,has_obligation}`、`sell_on_clause`、`deal_result`、`data_source`、`case_origin`、`confidence`、`observed_at`；相似匹配额外返回 `match_pct`、`matched_features`、`differences`。

## 6. 提醒字段

复用 `alerts`：`alert_id`、`instance_id`、`player_name`、`type`（机会类型）、`severity`、`title`、`message`、`read_at`、`created_at`。唯一键含标题，同一球员同一类型不会重复提醒。
