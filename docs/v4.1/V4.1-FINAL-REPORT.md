## 3. 分层改动说明

### 3.1 主题系统（P1）
- `tokens.css`：品牌蓝 `#356AE6 → #315FCE`；语义色改为低饱和；`--sm-accent-violet` 兼容别名统一指向品牌蓝（取消紫色系列）；新增 `--sm-surface-hover`、`--sm-fs-page`、`--sm-fs-section`；圆角 7/10/12；阴影更克制。
- `base.css`：移除紫色径向渐变；选中色、脉冲点（emerald → 成功绿）归一。
- `element.css`：标签 / 警告 / 输入聚焦 / 主按钮 / 表格悬停全部改用令牌；删除重复的旧色阶定义。
- `chart.ts`：调色板改为品牌蓝 + 低饱和语义色 + 中性灰；删除 `violet` 系列（改 `teal`）；雷达、散点、直方图、资金流向同步。

### 3.2 应用外壳（P2）
- `App.vue` 导航重排：
  - 总览：首页
  - 球探工作台：球员探索、关注名单、球员对比、阵容分析、球员发展、表现分析
  - 转会中心：引援机会、转会情报、**AI 转会总监**
  - 智能总监：AI 足球总监、AI 球探助手
  - 游戏管理：游戏数据、存档管理
  - 高级诊断（默认折叠）：角色球探、身份复核、身份中心、待确认球员、数据治理
- 顶栏改为纯白实色（移除毛玻璃 `backdrop-filter`），保留页面名 / 全局搜索 / 存档选择 / 同步状态 / 通知 / 用户菜单。
- 侧栏选中态、头像描边、遮罩色改用品牌蓝令牌。

## 6. 截图与分辨率验收

- 目录：`docs/reports/v4.1-light/`
