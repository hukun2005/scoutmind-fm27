# 评分与成本模型

本文件记录 ScoutMind V2 全部量化模型的口径：公式、权重、归一化方式、缺失数据处理和算法版本号。
代码是唯一事实来源，本文件必须与 `backend/app/analytics/` 同步修改。

通用规则：

- 每个模型都在响应的 `algorithm_version` 字段里报告版本，评分只在同一版本内可比。
- 缺失输入的维度返回 `value: null` 与 `missing[]`，权重按可用维度重新分配；**绝不用 0 代替缺失**。
- 所有 0-100 分数都由观测字段计算；没有任何分数来自语言模型。

## 1. 阵容评分（SquadScore）

`algorithm_version = squad-score-1`，实现于 `app/analytics/squad.py`。

```
SquadScore = w_C·C + w_D·D + w_A·A + w_T·T + w_W·W + w_P·P
默认权重     0.25    0.20    0.15    0.15    0.15    0.10
```

| 维度 | 含义 | 计算 |
| --- | --- | --- |
| C 位置覆盖 | 十个位置是否有球员可用 | 每个位置 `min(实际人数/最低要求, 1)`，按位置重要性加权平均 |
| D 阵容深度 | 替补是否够用 | 每个位置的第二人选与首选能力差距，映射到 0.4-1.0，再按重要性加权 |
| A 年龄结构 | 与基线年龄分布的距离 | `1 − 0.5·Σ|实际占比 − 基线占比|`，基线见下表 |
| T 战术适配 | 队内可评估球员的角色评分均值 | `best_role_score` 的属性加权均值（覆盖 < 50% 的球员不参与） |
| W 工资结构 | 集中度与低产出高薪 | 从 100 起扣：前 3 名工资占比 > 45% 的部分、工资高于中位数但出场低于中位数的人数 |
| P 潜力储备 | U23 人数与 PA−CA 空间 | `0.5·min(1, U23人数/期望) + 0.5·min(1, 平均空间/25)` |

位置最低人数要求：GK 2、CB 4、LB 2、RB 2、DM 2、CM 3、AM 1、LW 2、RW 2、ST 2。
位置重要性：GK/CB/CM/ST 1.0，LB/RB/DM 0.8，AM/LW/RW 0.7。
年龄基线占比：17-20 22%、21-24 30%、25-28 28%、29-31 15%、32+ 5%。
替补质量窗口：第二人选能力不低于首选 30 点即视为合格替补（窗口内线性给分）。

权重模板（`tactical_profiles`，可按存档修改，权重自动归一化到 1）：

| 模板 | C | D | A | T | W | P |
| --- | --- | --- | --- | --- | --- | --- |
| 均衡评估 balanced | 0.25 | 0.20 | 0.15 | 0.15 | 0.15 | 0.10 |
| 争冠阵容 contender | 0.30 | 0.25 | 0.10 | 0.20 | 0.10 | 0.05 |
| 重建期 rebuild | 0.15 | 0.15 | 0.20 | 0.10 | 0.10 | 0.30 |
| 保级/升班 survival | 0.35 | 0.30 | 0.10 | 0.15 | 0.05 | 0.05 |
| 青训建队 youth | 0.15 | 0.15 | 0.25 | 0.10 | 0.05 | 0.30 |

位置深度状态：无人=空缺；人数低于要求且不足一半=危险，否则=一般；替补质量 < 0.5=一般；
人数超过要求 +2=拥挤；其余=良好。

## 2. 球员评分（PlayerScore）

`algorithm_version = player-score-1`，实现于 `app/analytics/recruitment.py`。

```
PlayerScore = w1·A + w2·P + w3·T + w4·F + w5·V + w6·R
```

| 维度 | 定义 | 数据来源 |
| --- | --- | --- |
| A 当前能力 | `CA / 200 × 100`；缺 CA 时退回位置属性评分并标注 | 快照 `ca` |
| P 潜力 | `PA / 200 × 100` | 快照 `pa` |
| T 战术适配 | 位置属性模板加权分（0-100），同时报告属性覆盖率 | 快照属性 |
| F 比赛表现 | 位置相关每 90 分钟产出的同位置百分位 | `player_statistics` |
| V 转会价值 | 同位置同年龄段身价百分位的反向值（越便宜越高） | 快照 `market_value` |
| R 发展空间 | `min(1, (PA−CA)/30) × 年龄系数`；年龄系数 `clamp((30−age)/12, 0.2, 1)` | 快照 `ca/pa/age` |

维度权重按位置组：

| 位置组 | A | P | T | F | V | R |
| --- | --- | --- | --- | --- | --- | --- |
| GK | 0.30 | 0.15 | 0.20 | 0.15 | 0.15 | 0.05 |
| DF | 0.28 | 0.17 | 0.20 | 0.15 | 0.15 | 0.05 |
| MF | 0.25 | 0.20 | 0.20 | 0.15 | 0.15 | 0.05 |
| FW | 0.26 | 0.20 | 0.18 | 0.16 | 0.15 | 0.05 |

百分位需要同位置 ≥ 5 份可用样本，否则该维度不可用。

### 隐藏价值规则

| 规则 | 触发条件 | 依赖字段 |
| --- | --- | --- |
| 合同即将到期 | 合同 ≤ 12 个月 | `contract_end` |
| 强队缺少出场机会的年轻人 | 声誉 ≥ 7000、U23、出场 < 900 分钟 | `club_reputation`、`minutes_played`、`age` |
| 低级别联赛突出球员 | 联赛级别低于本队且 CA 接近本队中位数 | `club_league`、`ca` |
| 身价低但战术契合 | 身价同位置 ≤ 35 分位且适配 ≥ 65 | `market_value`、`attributes` |
| 高潜力低工资年轻人 | ≤ 21 岁、PA−CA ≥ 20、工资低于同龄中位数 | `pa`、`ca`、`wage`、`age` |
| 被俱乐部挂牌 | 需要挂牌字段 | 当前数据源未提供 → 明确列为无法评估 |
| 可通过租借获得 | 需要租借状态字段 | 当前数据源未提供 → 明确列为无法评估 |

## 3. 发展模型

`algorithm_version = development-1`，实现于 `app/analytics/development.py`。

```
GrowthRate = (CA_t − CA_t−1) / Δ月
```

- 区间少于 1 个月不给速率；只有一个快照时整份成长结论为「数据不足」。
- 分类：`fast ≥ 1.0`、`steady ≥ 0.3`、`flat > −0.3`、`declining ≤ −0.3`（单位：CA/月）。
- 停滞判定：最近 3 个快照 CA 不变且跨度 ≥ 8 个月。

潜力区间（**不是精确 CA 预测**）：

```
projected = CA + GrowthRate × (24 − age) × 12 × 0.6
区间 = [projected × 0.75, min(PA, projected × 1.25)]
等级：projected/PA ≥ 0.95 大概率达标；≥ 0.85 可能接近；≥ 0.70 有差距；否则停滞风险高
```

等级阈值同时作为 `probability` 字段（0-1）返回，界面按等级与区间展示，不展示为「未来 CA」。

## 4. 表现模型

`algorithm_version = performance-1`，实现于 `app/analytics/performance.py`。

- 每 90 分钟值 = 累计值 × 90 / 出场分钟；分母缺失时该指标不可用。
- 百分位在同存档、同位置组、有赛季统计的球员之间计算，样本 < 5 时不给。
- 指标：前锋 进球/射正/预期进球/助攻；中场 助攻/关键传球/抢断/成功传球；
  后卫 抢断/拦截/解围/争顶；门将 扑救/失球（反向）/零封。
- 趋势：赛季对赛季可直接比较；`last5` / `last10` 需要逐场统计，未提供时明确列为不可用。
- 能力 vs 表现：`产出百分位 − 能力百分位`，|差| ≥ 0.15 判为「表现优于/低于能力」。

## 5. 转会成本与投资

`algorithm_version = deal-model-1`，实现于 `app/analytics/deals.py`。

```
TotalCost = TransferFee + SigningFee + AgentFee + WageCost + Bonus
InvestmentScore = (ExpectedFutureValue − TotalCost) / TotalCost
```

- 每个成本项带 `status`：`observed`（存档读数）、`assumed`（模型假设）、`unavailable`（数据源未提供）、
  `conditional`（条款未触发）。
- `WageCost = 工资 × 周期系数 × 合同年限`；周期系数 周 52 / 月 12 / 年 1，默认按周计算。
  **工资周期与合同年限是假设**，请求可以覆盖（`wage_period`、`contract_years`）。
- 存在 `unavailable` 项时，合计标记为「已知成本下限」而不是总成本。
- `ExpectedFutureValue` 优先取可比成交估值中位数；样本不足时退回当前身价并标注为假设。
- 缺少总成本时拒绝计算投资效率，返回原因而不是 0。

### 交易类型体系

| 类型 | 处理方式 | 进入价格统计 |
| --- | --- | --- |
| 正式转会 | 记录成交金额与时间 | 是 |
| 租借 | 只记录租借费与期限 | 否 |
| 租借附买断 | 租借费与买断条款分开，触发前不计入 | 否 |
| 自由转会 | 转会费为零，保留其他成本 | 否 |
| 解约金买断 | 按已支付金额记录 | 是 |
| 球员交换 | 缺作价时不计入 | 否 |
| 青训提拔 | 只记录工资成本 | 否 |
| 未完成交易 | 不计入实际支出 | 否 |
| 交易取消/失败 | 保留记录并标记状态 | 否 |
